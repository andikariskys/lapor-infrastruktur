# Lapor Infrastruktur

**Lapor Infrastruktur** adalah platform pelaporan masalah infrastruktur publik yang dirancang untuk memudahkan masyarakat dalam menyampaikan keluhan dan membantu pemerintah atau pengelola dalam memantau serta menangani kerusakan infrastruktur secara efisien.

## Struktur Proyek

Proyek ini terdiri dari tiga bagian utama:

1.  **`fastapi-backend/`**: Layanan backend API yang dibangun menggunakan **FastAPI (Python)**. Bertanggung jawab atas pengolahan data, autentikasi, dan logika bisnis.
2.  **`flutter-frontend/`**: Aplikasi mobile/multi-platform yang dibangun menggunakan **Flutter**. Digunakan oleh masyarakat untuk mengirimkan laporan secara langsung.
3.  **`laravel-frontend/`**: Portal web admin atau dashboard manajemen yang dibangun menggunakan **Laravel (PHP)**. Digunakan oleh pihak pengelola untuk memvalidasi dan menindaklanjuti laporan.
